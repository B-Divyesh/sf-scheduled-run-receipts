Policy · 28 August 2026

Privacy

Scheduled Run Receipts is local-first. The CLI does not send schedules, keys, receipts, commands, or reports to us or to any third party.

CLI data

The CLI stores its versioned JSON state in the path you select, or in your operating system's local data directory. Job signing keys are stored in that file. Exported key bundles and reports are written only where you direct the CLI.

Website data

This website uses no analytics, advertising, cookies, accounts, remote fonts, or third-party scripts. If you choose a JSON report in the evidence viewer, the browser reads it locally. It is not uploaded.

Network and deletion

The CLI has no network client. Remove the state file and any exported key or report files to delete your data. Your hosting provider may retain ordinary short-lived access logs for security and operations.

Contact

For privacy questions, open an issue in the public source repository without including secrets or receipt tokens.
